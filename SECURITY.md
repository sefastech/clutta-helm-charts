# Security policy

Please do not disclose a suspected vulnerability in a public issue.

Send reports to [support@clutta.io](mailto:support@clutta.io). Include the
affected chart version, Helm version, Kubernetes version, impact, and the
smallest safe reproduction you can provide. Do not include live credentials,
customer evidence, or other sensitive data.

General installation and configuration questions belong in
[GitHub Issues](https://github.com/sefastech/clutta-helm-charts/issues).
